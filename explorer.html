This is a *visual encoding proposal*, not a confirmed color-readable or compression format. We need to test distinguishability, contrast, reproducibility and accessibility.

Classic tile / current demo
Pure glyph / new concept

The original two-mark tile remains intact for comparison. The proposed native glyph carries a shape index and a palette index, both visible without a surrounding tile.

16 shapes × 16 colors256 visual combinations
RGB824 bits = 16,777,216 digital RGB values
RGBA832 bits = 4,294,967,296 digital combinations

RGB and RGBA counts describe raw channel combinations, not guaranteed distinguishable glyphs or reduced storage. Alpha is transparency, not independent “blackness”; black (K) belongs to CMYK. Visual color should never be the only decoder without a robust underlying numeric encoding.
