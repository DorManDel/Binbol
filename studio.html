01 / THE PROJECT

One concept. Three representations.

We are not inventing information out of nothing. We are designing how to encode, interpret, render and measure it.

{ }

Semantic meaning

An operation has an explicit contract: SET, ADD, SUBTRACT, PRINT. A dictionary maps optional symbols and words to this meaning.

0101

Binary storage

The engine stores opcodes and operands as bytes or bitfields. The target system determines how we pack and decode identifiers.

◈

Visual language

Glyphs, colors, patterns and stories are alternative views of the same structure, not new bits hidden inside a picture.

Research rule: Fewer visible symbols do not automatically mean fewer stored bytes or faster compiled code. We measure the entire encoded format, including its dictionary and runtime costs.

07 / SECURITY RESEARCH
Hidden meaning is not encryption.
Binbol can compact or disguise familiar phrases, but a private dictionary cannot guarantee confidentiality or integrity. Security is an independent layer, with its own costs and threat model.

  

    
▦
Semantic IDs
01 could mean a long phrase to peers with a dictionary. Patterns, lengths and repeat counts remain visible.
ENCODING, NOT CRYPTOGRAPHY

    
⇄
Dictionary rotation
Remapping IDs changes the packet representation; it does not give the guarantees of cryptographic key rotation or tamper detection.
OBFUSCATION, NOT ENCRYPTION

    
♢
Authenticated encryption
A future vetted AEAD/E2E layer can protect the encoded payload. Nonces, authentication tags, key management and protocol framing cost extra bytes.
STANDARD CRYPTO · FUTURE WORK

  

  

    
PROPOSED DESIGN · NOT YET IMPLEMENTED
Encode first. Protect separately.
THREAT MODEL REQUIRED

    
Source→Binbol codec→AEAD protect→Network→Verify + decode

    
Important: combining compression with encryption can leak secrets through ciphertext length when attacker-controlled input and secret data share a compression context. We must evaluate this before enabling secure transport.

    
Current BNB1 packets use only a 16-bit noncryptographic dictionary checksum. Do not use them to protect confidential data or authenticate messages. The full ZIP package contains the Hebrew threat-model document and a curated reference guide.
