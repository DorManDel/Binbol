# Binbol · מסלול העבודה שלנו (ללא סיסמאות מפוצצות)

## למה אנחנו בונים את זה?

כדי לבדוק האם אפשר לארוז מידע שחוזר על עצמו או בנוי בצורה קבועה בפחות בתים, ובאותה העת להציג אותו בצורה שקל להבין, לערוך וללמוד. אנחנו לא מניחים מראש שהתוצאה תנצח פתרונות קיימים.

| שלב | מה עושים? | למה? | איך? | איך נדע שעבד? |
| --- | --- | --- | --- | --- |
| 0. מגדירים בעיה | בוחרים הודעות לדוגמה ומטרת מדידה | בלי מדד קל להתבלבל בין סמל יפה לדחיסה | קובצי דוגמה ו־UTF-8 byte count | נתוני פתיחה שניתן לשחזר |
| 1. מקודדים | מחליפים רצפים נפוצים במזהים | לשלוח פחות חזרות | מילון, Token IDs, Literal fallback | Decode זהה לקלט |
| 2. אורזים | מקצים ביטים באופן מתוכנן | להפחית padding ותקורה | Bitfields, Packed IDs, Varints, Opcode layouts | מספר בתים מלא ולא רק תווים |
| 3. מסנכרנים מילון | שני צדדים מסכימים על פירוש ID | למנוע פענוח שגוי | Version / dictionary hash / strict rejection | שגיאת mismatch בלי פלט מטעה |
| 4. מעבירים | יוצרים פורמט קובץ או הודעת רשת | לבדוק שימוש אמיתי בין מחשבים | `.bnb`, בעתיד sockets/HTTP | שחזור זהה והעברה אמיתית |
| 5. מציגים | מציירים את אותו מזהה כסמל | קריאות ולימוד | GlyphForge, טבלת סמלים, אנימציה | לא משנה את הנתונים |
| 6. מריצים | ממפים Opcode לפעולה מוגדרת | ניסוי בשפה קומפקטית | GlyphScript, Parser, C VM | התוצאה זהה לתוכנית המקור |
| 7. משווים | מריצים את אותם נתונים במתחרים | לזהות יתרון אמיתי | Raw, gzip, Brotli, Zstd, Protobuf | מדדים חוזרים ושקופים |
| 8. מגנים | מוסיפים שכבת אבטחה תקנית | סודיות ושלמות בתקשורת | Threat model, TLS/AEAD/HPKE, key management | tamper/wrong key נכשל; בלי טענות על 'הצפנת מילון' |
| 9. מתאימים | בוחרים פרופיל למערכת ולסוג קלט | לא בכל מקום אותו ייצוג הכי טוב | Instruction Profiles + automatic profiler | שיפור מדיד ביחס לבסיס השוואה |

## מסלולים נפרדים כדי לא לערבב את המדידות

- **Lossless:** מקור ושחזור זהים בית־לבית, גם בעברית, אימוג'ים וקבצים בינאריים.
- **Lossy:** רק באישור ובהגדרת סטיית איכות, למשל קוונטיזציה מספרית או מדיה; לא לקוד ולפקודות שחייבים להיות מדויקים.
- **Security:** הצפנה מאומתת אינה דחיסה; מילון סודי אינו צופן; יש להתייחס לסיכוני דליפת אורכי הודעות.
- **Visualization:** סמלים אינם קסם שמוסיף מידע בחינם. הגריד מציג ביטים שכבר קיימים.
